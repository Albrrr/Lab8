Graceful degredation is the methodology of designing applications in a way that ensures that they do not completely fail in the event that certains technologies it is built with fails. Service workers allow you to build websites that work even after a network failure as the service workers listen to network requests from the site and store the response within the browser. This means that even during a network failure, the service workers will receive the network request from the site and return the appropriate response that is has stored locally if it had been stored previously. This is related to the idea of graceful degredation as the website would continue to keep working with the help of the service workers evenin the face of the failure of an important technology, which is the network in this case.
